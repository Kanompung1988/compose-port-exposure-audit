# Contributing

Open an issue with a synthetic (non-sensitive) reproduction before proposing a change. Please include the exact CLI command, Python version, and expected/actual classification. Run `python -m unittest discover -s tests -v` and update fixture cases. Avoid committing production configuration, credentials or customer files. PRs must pass CI before merge.

The Area Zero official logo is an authorized project brand asset, not an MIT grant for downstream projects; replace it when rebranding a fork.
